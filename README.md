# sherpa

Единый вход к агентам проектов на локальной машине: пишешь в Telegram, работает агент в папке нужного проекта.

В личном чате задачу разбирает привратник и направляет её в нужный проект. В топике супергруппы работает агент этого проекта: ответ и ход работы видны в ленте, подтверждения приходят кнопками.

## Как устроено

```
Telegram ⇄ бот (сервер) ⇄ WebSocket-канал ⇄ раннер (рядом с проектами) → агент в папке проекта
```

- **Бот** (`packages/bot`) — только транспорт Telegram. Ничего не знает о проектах и правах.
- **Раннер** (`packages/runner`) — живёт рядом с проектами: реестр папок, права, маршрутизация, запуск агента.
- **Контракт** (`packages/contract`) — типы и кодирование сообщений между ботом и раннером.

Состояние: контракт и бот готовы, раннер пока заглушка.

## Запуск

Нужен Node 22+.

```bash
cp .env.example .env   # заполнить токен бота, user id, чаты, секрет канала
npm install
npm run dev:bot
npm run dev:runner
```

Проверка перед коммитом: `npm run check` (типы, линт, формат, тесты).

Переменные окружения и протокол канала описаны в [`packages/bot/README.md`](packages/bot/README.md) и [`packages/contract/README.md`](packages/contract/README.md). Выкат бота на VPS — [`deploy/README.md`](deploy/README.md).
